# راهنمای سریع دانلود، جابجایی و ارسال با ایمیل

اگر دانلود مستقیم برای شما سخت است، از بسته‌ی قابل‌انتقال استفاده کنید.

## ساخت بسته قابل‌انتقال (ZIP)

در ترمینال پروژه این دستور را اجرا کنید:

```bash
python3 build_portable_package.py
```

خروجی ساخته می‌شود در:

`dist/rsi_spot_bot_portable.zip`

## ارسال به ایمیل

1. وارد ایمیل شوید (Gmail/Outlook).
2. روی Attach (ضمیمه) کلیک کنید.
3. فایل `rsi_spot_bot_portable.zip` را انتخاب کنید.
4. ارسال کنید.

## اجرا در سیستم مقصد

1. فایل ZIP را Extract کنید.
2. در ویندوز: `run_windows.bat` را اجرا کنید.
3. در لینوکس/مک: `run_linux.sh` را اجرا کنید.

این بسته شامل فایل اصلی ربات + dependencies موردنیاز است و برای جابجایی ساده طراحی شده است.
